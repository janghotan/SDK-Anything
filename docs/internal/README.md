# Internal process records

This directory keeps historical build and release records for auditability.
They are **not** user-facing documentation and may reference branches, prompts,
or file paths that no longer exist.

- `STATE.md` — implementation checkpoint at the time of the v0.1.0 release
- `IMPLEMENTATION-JOURNAL.md` — chronological engineering journal through v0.1.0

For current documentation, start with the [README](../../README.md),
[architecture](../architecture.md), [design](../design.md),
[security model](../security.md), and [release evidence](../release-evidence.md).
