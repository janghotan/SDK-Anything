## 3. Subsystem Hardening Evidence

### A. Standalone Generated Project Independence (Phase 01)
- Verified that projects generated into isolated temporary directories (`os.tmpdir()`) outside the SDK-Anything repository compile with zero TypeScript diagnostics (`ts.getPreEmitDiagnostics`).
- Confirmed generated projects contain zero relative imports back into the generator source tree (`../src/`) and zero `file:` dependencies.
- Confirmed generated MCP server and CLI adapters include a standalone copy of `runtime.ts` handling input schema validation, client lifecycle, credentials, and error normalization.

### B. Real SDK Compatibility & Re-Export Handling (Phase 02)
- Enhanced `src/analyzer/export-scanner.ts` so that aggregate re-export packages (such as `@turf/turf` v7 re-exporting 111 sub-packages) cleanly discover all operations and surface them in `unresolved` with actionable overrides instructions.
- Verified that human overrides (`sdk-anything.overrides.json`) promote unresolved symbols to executable tools with custom input schemas and effect classifications without altering SDK source.
- Verified pathful validation errors when overrides target non-existent operation IDs.

### C. Security & Policy Parity (Phase 03)
- **Non-Interactive Destructive Protection:** Hardened `src/runtime/policy-enforcer.ts` so that in non-interactive / non-TTY environments (e.g. CI, piped shell commands), destructive operations strictly fail closed with `POLICY_DENIED` unless explicitly authorized via `--allow-destructive` / `allowDestructive: true`.
- **Secret Redaction:** Tested synthetic secrets and verified authorization headers (`Bearer [REDACTED]`) and key patterns are stripped from error logs and outputs.
- **Output Confinement:** Verified in `src/generators/index.ts` that all written files must resolve strictly within the destination directory, rejecting path traversal attempts.

### D. Packaging Hygiene & CI Workflow (Phase 04)
- Added explicit `files` whitelist in `package.json` covering `dist/`, `schema/`, `skills/`, `README.md`, `README.zh-CN.md`, and `LICENSE`.
- Confirmed `npm pack --dry-run` produces a clean 82.5 kB package (363.2 kB unpacked) containing only distribution files and zero test fixtures or internal plans.
- Configured GitHub Actions workflow at `.github/workflows/ci.yml` across Node.js 20 and 22 LTS testing formatting, typecheck, lint, full tests, build, and package dry-run.

### E. Documentation & User Journeys (Phase 05)
- Verified bilingual documentation ([README.md](README.md) and [README.zh-CN.md](README.zh-CN.md)) with hero banners and language switchers.
- Tested exact quickstart commands on local sample SDK and confirmed outputs match documented behavior.
- Documented generator orchestration skill at [skills/sdk-anything/SKILL.md](skills/sdk-anything/SKILL.md).

## 4. Known Limitations & Accepted Risks

1. **Language Scope:** v0.1 is strictly scoped to TypeScript and JavaScript SDKs. Other languages (Python, Go, Rust) are deferred to future major versions.
2. **Container Sandbox Prerequisites:** Running tests in `--sandbox` requires local Docker or Podman. When absent, the harness fails closed with an actionable diagnostic message and refuses silent fallback to host execution.
3. **Live AI Integration:** The AI proposal layer was verified using deterministic mock OpenAI-compatible HTTP fixtures; no live third-party API credentials were required or stored.
4. **Operation Scope:** Generated operations are atomic. Multi-step composite workflows are orchestrated by consuming LLM agents via `SKILL.md`.
